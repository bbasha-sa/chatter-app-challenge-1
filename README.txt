chatter|app — Challenge 1

طريقة التشغيل
افتح index.html باستخدام Edge أو Chrome. يعمل المشروع دون إنترنت أو تثبيت برامج.

محتويات المشروع
index.html: الصفحة كاملة مع CSS داخلي.
README.txt: إرشادات التشغيل.

تمت إعادة إنشاء المشروع وفق صور تعليمات Challenge 1 من المحادثة السابقة:
- عنوان الصفحة chatter|app وقسما القنوات والمحادثة، والمحادثة أسفل القنوات.
- Favorites وRegular وأربع قنوات بأسماء عريضة وتواريخ صغيرة.
- عنوان القناة وزر FAVORITE وثلاث رسائل بأسماء المستخدمين وأوقاتها.
- حقل إدخال وزر SEND.
- الخطوط Roboto ثم Arial ثم sans-serif، واللونان #00838f و#eeeeee.
- الأزرار بخلفية تركواز ونص أبيض كبير وأحرف كبيرة باستخدام CSS.

الأزرار للعرض فقط في الأسبوع الأول. لا يتضمن هذا التحدي JavaScript أو إرسال رسائل حقيقية.
عند عدم توفر Roboto على الجهاز، يستخدم المتصفح Arial تلقائيًا.

النقل اليدوي على Windows
فك ضغط chatter-app-challenge-1.zip داخل E:\edx المشاريع
ليصبح ملف الصفحة في E:\edx المشاريع\MYOA_MOOC\index.html.
احتفظ بهذه الملفات لتطويرها في الأسبوع الثاني.
